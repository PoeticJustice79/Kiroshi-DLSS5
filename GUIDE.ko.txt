▣ 지원 게임

  몬스터 헌터 와일즈
  드래곤즈 도그마 2  (DD2 전용 버전은 별도 저장소: DD2-DLSS5-Installer)
  파이널 판타지 7 리버스
  위처 3
  GTA V Enhanced
  사이버펑크 2077


▣ 쓰는 법

  1. 게임을 완전히 종료합니다.
  2. Install.cmd 를 더블클릭합니다.
  3. 드롭다운에서 게임을 고릅니다.
  4. [자동 탐지] → [0. 파일 받기] → [1. 검사] → [2. 설치] 순서로 누릅니다.
  5. 게임을 켭니다.


▣ 먼저 확인할 것

  · RTX 그래픽카드, NVIDIA 드라이버 616.56 이상

  · nvngx_dlssnr.dll ("DLSS-NR model")
      NVIDIA 파일이라 함께 배포하지 않습니다.
      RenoDX 디스코드에서 구하셔서 payload 폴더에 넣으세요.
      나머지 파일은 [0. 파일 받기] 가 자동으로 받아옵니다.


▣ 몬스터 헌터 와일즈 - 따로 챙길 것

  · REFramework 를 먼저 설치해야 합니다 (넥서스 모드). 이 도구가 설치해주지
    않습니다 - 이게 없으면 게임이 애초에 수정된 파일을 안 받아줍니다.

  · 주입 자리는 dxgi.dll 입니다. d3d12.dll 로 하면 부팅하자마자 크래시 납니다.
    게임 폴더에 숨겨진 무결성 검사 폴더(_storage_\)가 있는데 그게 d3d12.dll
    을 감시하는 걸로 보입니다.

  · REFramework 가 기본적으로 Insert 키를 오버레이로 쓰기 때문에, OptiScaler
    메뉴는 Delete 키로 자동 배정됩니다. 겹치지 않게 하기 위함입니다.

  · 이 게임은 다른 게임들과 다른 OptiScaler 버전(v0.2.0-patch1)을 받습니다.
    버전 궁합이 게임마다 다르기 때문입니다 - 최신이라고 항상 되는 게 아닙니다.

  · 리쉐이드를 같이 쓰고 싶으면: 리쉐이드 본체를 ReShade64.dll 로 이름 바꿔서
    게임 폴더에 넣고, OptiScaler.ini 의 [Plugins] 항목에서 LoadReshade 를
    true 로 바꾸세요. dxgi.dll 자리를 나눠 갖는 방식이 아니라 OptiScaler 가
    내부에서 리쉐이드를 불러주는 방식이라 이렇게 해야 둘 다 동시에 됩니다.
    이건 자동화돼 있지 않습니다 - 각자 쓰던 프리셋이 있을 거라 그대로 두었습니다.


▣ GTA V Enhanced - 따로 챙길 것

  · BattlEye 를 반드시 꺼야 합니다. 안 그러면 아무것도 로드되지 않습니다.
    록스타 런처 → 설정 → GTA V Enhanced → BattlEye 체크 해제.
    스토리 모드 전용이 됩니다 (온라인은 BattlEye 강제).


▣ 게임 안에서

  1. 그래픽 설정 → 업스케일러 = NVIDIA DLSS (DLAA 도 됨)
  2. 오버레이 키 (대부분 Insert, 몬헌 와일즈만 Delete) → OptiScaler 메뉴
  3. DLSS Neural Rendering 펼치기 → Enable Neural Rendering
  4. 초록색으로 Running - N ms per frame 뜨면 된 겁니다
  5. Save Settings 눌러야 다음에도 유지됩니다


▣ 되돌리기

  설치기 실행 → 게임 선택 → [복원]
  백업은 바탕화면 DLSS5-backup_<게임>_<시각> 폴더에 있습니다 (게임 폴더 밖).


▣ 주의

  · 실험 단계 물건입니다. 엔비디아 정식 배포 아닙니다.
  · 싱글 플레이 전용입니다. 안티치트 있는 곳에서 쓰지 마세요.
  · 게임/애드온이 업데이트되면 버전 궁합이 또 바뀔 수 있습니다. 갑자기 안
    되기 시작하면 설정 문제가 아니라 버전 문제일 가능성이 큽니다.
